diffkit

Agentic-first text diff and patch service. Generate unified diffs, apply patches, compare texts with word-level diffs, and summarize changes.

Go Single Binary MIT
View on GitHub Releases

Quick Start

make build
./diffkit

# Generate a diff
curl "http://localhost:8472/diff?old=hello+world&new=hello+earth"

# Apply a patch
curl -X POST http://localhost:8472/patch \
  -H "Content-Type: application/json" \
  -d '{"text":"hello\nworld","patch":"--- old\n+++ new\n@@ -1,2 +1,2 @@\n hello\n-world\n+earth\n"}'

# Word-level diff
curl "http://localhost:8472/worddiff?old=hello+world&new=hello+earth"

# Diff summary
curl "http://localhost:8472/summary?old=a%0Ab%0Ac&new=a%0AB%0Ac%0Ad"

Principles

Agent IS the Interface

No UI, no SDK. The AI agent is the user. The API is the product.

Plain Text by Default

Unified diff format, grepable, token-cheap. JSON on demand.

Instructive Errors

Every 4xx includes a hint telling the agent what to do next.

Self-Documenting

GET /help returns a one-page operating manual the agent loads at runtime.

Single Static Binary

Go, zero external dependencies, CGO_ENABLED=0. Deploys as one file.

Zero Config

Runs out of the box. Config layered: defaults < env < flags.

API Reference

MethodEndpointDescription
GET/helpOperating manual
GET/healthHealth check
GET/POST/diffGenerate unified diff
GET/POST/patchApply a unified diff patch
GET/POST/worddiffWord-level diff
GET/POST/summaryDiff summary (added/removed/unchanged)
POST/mcpMCP endpoint for chat clients
